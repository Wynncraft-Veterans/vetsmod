# Vetsmod

> [!WARNING]
> # This is a temporary implementation.
> This Alpha build is VERY rough around the edges, unoptimised, and poorly coded!
> This is a TEMPORARY build to tie everyone over until a real version is ready.
> 
> **There will be bugs. Lots of them.**
> Except for alpha volunteers who have offered to help debug this temporary mess;
> **WE DO NOT RECOMMEND** ***ANYONE*** **USE THIS BUILD VERSION!**

Vetsmod is a client modification created by and for the [Wynncraft Veterans' Community](https://wynnvets.org).

This mod runs on fabric, depends on [Wynntils](https://modrinth.com/mod/wynntils/), [Fabric API](https://modrinth.com/mod/fabric-api), and optionally [Figura](https://modrinth.com/mod/figura).

This is an early alpha version targetted at volunteers among the members of VETS.
